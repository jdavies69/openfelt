# Reporting security issues

Use GitHub's private vulnerability reporting when enabled, or privately contact the repository owner through GitHub before disclosing exploitable details. Do not paste credentials, personal histories or unredacted logs into public issues. Public issues may describe non-sensitive symptoms and reproduction steps with artificial fixtures.

OpenFelt is local play-money learning software. Optional provider requests go directly to the explicitly selected endpoint with the user's own credential. No maintainer-funded key is supplied. Provider privacy and billing terms are outside this project's control.
